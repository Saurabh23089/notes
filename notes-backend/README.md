# Notes Backend

This is the backend for the Notes App built using **Node.js**, **Express**, and **MongoDB**. It provides RESTful APIs to add and get all notes.

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- MongoDB instance (local or cloud)
- npm or yarn

### 📦 Installation

```bash
cd notes-backend
npm install
npm run dev
